Resources

Reference material for Wi-Fi security labs and exercises.

Glossary

SSID

The Wi-Fi network name broadcast by an access point.

BSSID

The MAC address that uniquely identifies a wireless access point.

Handshake

The authentication exchange captured during WPA/WPA2 connection setup.

PMKID

A value used in WPA/WPA2 authentication that can sometimes be attacked offline.

Deauthentication

A management frame used to disconnect a client from an access point.

Monitor Mode

A wireless interface mode that allows packet capture without joining a network.

WPA2

A widely used Wi-Fi security standard using PSK or Enterprise authentication.

WPA3

A newer Wi-Fi security standard with stronger protections such as SAE.

Tool Guides

airmon-ng

Used to enable monitor mode on a wireless interface.

sudo airmon-ng start wlan0

airodump-ng

Captures Wi-Fi traffic, access points, clients, and handshakes.

sudo airodump-ng wlan0mon

aireplay-ng

Injects packets such as deauthentication frames.

sudo aireplay-ng --deauth 10 -a <BSSID> wlan0mon

Wireshark

Analyzes PCAP captures and inspects management, control, and data frames.

wireshark capture.pcap

hashcat

Performs GPU-accelerated password cracking against captured hashes.

hashcat -m 22000 hash.hc22000 wordlist.txt

hcxdumptool

Captures PMKID and EAPOL material for offline analysis.

sudo hcxdumptool -i wlan0mon -o capture.pcapng

Cheat Sheets

Enable Monitor Mode

sudo airmon-ng start wlan0

Scan for Networks

sudo airodump-ng wlan0mon

Capture a Handshake

sudo airodump-ng -c 6 --bssid <BSSID> -w capture wlan0mon

Deauth a Client

sudo aireplay-ng --deauth 10 -a <BSSID> -c <CLIENT> wlan0mon

Convert PMKID/EAPOL for Hashcat

hcxpcapngtool -o hash.hc22000 capture.pcapng

Run Hashcat

hashcat -m 22000 hash.hc22000 wordlist.txt
